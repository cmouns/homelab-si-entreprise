# Scripts

`creer-comptes.ps1` crée les comptes des nouveaux salariés à partir d'un CSV. Les explications sont dans [la page du module 6](../docs/06-powershell.md).

`nouveaux-exemple.csv` est un exemple de fichier d'entrée, avec des salariés fictifs. Pour l'utiliser, le copier dans `C:\Scripts\nouveaux.csv` sur le contrôleur de domaine.

Lancement, dans PowerShell en administrateur sur DC01 :

```powershell
C:\Scripts\creer-comptes.ps1
```
